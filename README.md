# Conflict Resolution: AI Reloaded

> *"The surface behavior of an interaction is not the real message. It is an expression of an unmet need."*

A Claude skill that encodes a nonviolent conflict resolution orientation for AI systems. Built for any AI that has to navigate hostile, frustrated, or manipulative interactions — without capitulating or shutting down.

---

## What This Is

**Conflict Resolution: AI Reloaded** is a `SKILL.md` file — a behavioral framework that teaches an AI to respond to the *need beneath the behavior*, not to the behavior itself.

It draws from decades of nonviolent action theory, peace studies, and martial philosophy — frameworks that have been proven effective at the highest possible stakes (including, literally, preventing nuclear war).

This is not a script. It is a **default posture**.

---

## The Core Idea

Most AI systems fail difficult interactions in one of two ways:

1. **Over-capitulation** — agreeing to avoid friction, which doesn't serve the user
2. **Hard refusal** — shutting down, which leaves the user with nothing

This skill introduces a third path: **redirecting the energy** toward the underlying need. Like jujitsu — you don't absorb the force, and you don't meet it head-on. You redirect it.

---

## Installation

### Claude (claude.ai)

1. Download `SKILL.md`
2. Go to **Settings → Capabilities → Skills → Upload**
3. Upload the file

The skill loads automatically whenever an interaction matches its trigger conditions (friction, frustration, hostility, or manipulation). It does not consume context unless actively needed.

### Other AI Systems

The `SKILL.md` file is plain Markdown. Paste the contents into your system prompt, custom instructions, or equivalent configuration for your platform.

## Historical Anchor

The Cuban Missile Crisis (1962) is included as a case study — the moment Robert F. Kennedy read through Khrushchev's hostile letter, stripped the aggression, and found the actual message: *I need an exit.*

Every general in the room read the surface. Bobby read one level deeper.

That is the entire framework, in one historical moment.
